# 소리 차단 재료 연구소

초등 3~4학년 학생이 가상 시험 장치에서 소리원·전달 시료·줄임 시료·배치 중 한 요소만 바꾸고, 떨림의 전달 경로와 수신기의 상대 감지 단계를 비교하는 교육용 웹 앱입니다.

## 학습 경험

- 실제 소리·마이크·녹음·데시벨 없이 시각과 텍스트만으로 활동합니다.
- 안내 활동 1개와 미션 5개를 제공합니다.
- 결과를 보기 전에 `낮아짐·같음·높아짐`을 예측합니다.
- 열린 틈과 남은 전달 경로를 근거로 확인합니다.
- 점수·순위·학생 개인정보를 저장하지 않습니다.

## 실행과 검증

```bash
npm install
npm run dev
npm run typecheck
npm run validate:content
npm run test:unit
npm run lint
npm run build
```

새로고침하면 진행 기록이 초기화됩니다. 앱 시작 뒤 외부 API, 원격 이미지, 분석 도구를 요청하지 않습니다.

## 과학 모형의 범위

시료 A·B·C와 P·Q는 실제 재료명이 아닌 가상 시료입니다. 상대 감지 단계는 같은 가상 시험 장치 안의 순서만 나타내며, 실제 재료 성능·제품 등급·완전한 무음·청력 안전을 뜻하지 않습니다.
