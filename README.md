# 소리 차단 재료 연구소

초등 3~4학년 학생이 컴퓨터 모형에서 한 번에 한 가지만 바꾸며 소리가 지나가는 길을 찾아보는 교육용 웹 앱입니다.

학생은 `소리 내는 곳 → 재료 모형 → 덧댄 모형 → 소리 받는 곳`의 흐름을 따라가며, 먼저 생각한 답과 모형 실험 결과를 비교합니다.

## 학습 경험

- 실제 소리·마이크·녹음 없이 화면과 글로 활동합니다.
- 연습 1개와 미션 5개를 제공합니다.
- 결과를 보기 전에 `더 작을 것 같아요·비슷할 것 같아요·더 클 것 같아요` 중 하나를 고릅니다.
- 열린 틈과 소리가 지난 길을 단서로 살펴봅니다.
- 점수·순위·학생 개인정보를 저장하지 않습니다.

## 실행과 검증

```bash
npm install
npm run dev
npm run typecheck
npm run validate:content
npm run test:unit
npm run lint
npm run build
```

새로고침하면 진행 기록이 초기화됩니다. 앱 시작 뒤 외부 API, 원격 이미지, 분석 도구를 요청하지 않습니다.

## GitHub Pages 배포

서버·로그인·외부 API 없이 실행되는 학습 화면은 GitHub Pages에서 제공합니다.

배포 주소: https://wbmaker2.github.io/sound-blocking-material-lab/

```bash
npm run build:pages
```

## 컴퓨터 모형의 약속

재료 모형 A·B·C와 덧댄 모형 P·Q는 실제 제품이 아니라 이 앱 안에서 만든 모형입니다. `크게 표시됨·작게 표시됨`은 같은 컴퓨터 모형 안에서 비교하기 위한 표시이며, 실제로 잰 소리 크기나 실제 재료의 성능·안전을 뜻하지 않습니다.
