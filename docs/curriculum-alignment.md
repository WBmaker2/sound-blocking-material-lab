# 교육과정 연결

- `[4과07-01]`: 소리원 떨림과 시험 신호 시작의 관계를 가상 모형으로 일부 지원합니다. 실제 물체 관찰은 별도입니다.
- `[4과07-02]`: 같은 높낮이에서 약한 떨림과 강한 떨림의 상대 결과 비교만 지원합니다. 높낮이 만들기와 실제 소리 내기는 제외합니다.
- `[4과07-03]`: 여러 가상 물질을 통한 전달, 줄임 시료, 열린 틈과 남은 경로를 비교합니다. 실제 재료 조사와 생활 속 실천 전체를 대신하지 않습니다.

앱 완료만으로 세 성취기준 전체 달성을 평가하지 않습니다. 교사는 떨림 연결, 한 변인 통제, 전달 경로 확인, 범위를 줄여 말하기를 관찰합니다.
