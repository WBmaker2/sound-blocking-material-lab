# 콘텐츠 검수 안내

1. 모든 미션의 기준과 비교 설정이 정확히 한 요소만 다른지 확인합니다.
2. 활성 경로와 열린 틈이 화면 장치와 텍스트 경로에 같은 순서로 나타나는지 확인합니다.
3. 상대 결과 문장이 반드시 `이 가상 시험에서`의 범위를 유지하는지 확인합니다.
4. 실제 재료의 보편 순위, 수치 성능, 완전한 무음, 안전 보장으로 읽힐 문장을 제거합니다.
5. 조합 변경 시 기록, 테스트, 업데이트 내역을 함께 갱신합니다.

공개 수업 적용 전에는 초등 과학 지도 경험자와 소리 모형 검토 가능자가 독립적으로 원고를 검토하는 절차를 권장합니다.
