# 교사용 안내

## 권장 흐름

1. 작은 소리로 실제 물체의 떨림을 관찰합니다.
2. 화면 경로와 상대 감지 단계가 실제 소리 모습이나 측정 수치가 아님을 확인합니다.
3. 개인 또는 2인 모둠으로 안내 활동과 5개 미션을 진행합니다.
4. 학생이 바꾼 요소 하나와 남은 경로를 짝에게 설명합니다.
5. 교사가 검수한 안전한 재료로 작은 소리 확장 활동을 진행합니다.

예측이 다른 것을 실패로 평가하지 않습니다. 실제 활동은 큰 소리, 고함, 헤드폰 최대 음량, 깨지기 쉬운 물체, 날카로운 재료를 피하고 교사 감독 아래 진행합니다.
