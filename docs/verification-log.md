## 시각 콘셉트 충실도 기록

| 비교 항목 | 콘셉트 | 구현 결과 |
| --- | --- | --- |
| 색상 | 남색·청록·밝은 회색 바탕 | 동일한 색 역할과 대비 유지 |
| 상단 구조 | 브랜드, 진행 상태, 도움말 | 동일한 3영역 구조로 구현 |
| 장치 표현 | 소리원→시료→수신기 | CSS 도형과 점선 경로로 구현 |
| 비교 방식 | 기준/비교를 나란히 표시 | 결과 화면에서 2열 비교로 구현 |
| 결과 표시 | 수신기 단계 막대 | 5단 상대 감지계로 구현 |
| 근거 정리 | 바꾼 것·그대로인 것·남은 경로 | 별도 근거 단계와 최종 기록으로 확장 |

첫 화면의 핵심 문구는 기획안의 `소리가 지나가는 길과 줄어드는 조건을 비교해요`를 그대로 유지했습니다. 생성 콘셉트에 포함된 실제 재료명은 과학적 과장을 피하기 위해 A·B·C·P·Q 가상 라벨로 바꿨습니다. 초기 화면은 학습 진입에 집중하도록 콘셉트의 복잡한 조건 패널 대신 장치 미리보기를 사용하며, 실제 비교 패널은 미션 진입 뒤 표시됩니다.
